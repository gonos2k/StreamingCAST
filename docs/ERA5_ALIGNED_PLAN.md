# ERA5 실제 재고에 맞춘 개발계획 개정

작성: 2026-10-11. 기준 main: `6d9866a812172e1c36703731085c622dd1beef35`.
이 문서는 기존 계획의 **자료 확보·학습 순서·평가 분할·비용 가정**을 수정한다.
최종 목표인 전지구 실제 1시간 전이, 시간별 지상강수, 24h/12h 구조, 미분가능 NWP 연결은 유지한다.

## 2. 두 자료 프로파일을 분리한다

### A. 기존 캐시 활용: G29 + P6h (연구용, 구현 예정)

- 등압면 저장 순서: `[1000,850,700,500,250] hPa`.
- 순간장: T, Phi, u, v, q ×5층 + t2m/msl/u10/v10 = **29채널**.
- 별도 구간 출력: `total_precipitation_6hr` = **1채널**. 총 30채널.
- 전이 6h, 입력 시각 `[-6h,0h]`; 10일 예측은 40회 전이.
- 원본 강수는 m. 해당 변수가 실제 `(t-6h,t]`를 뜻하는지 생성 코드/메타데이터로 검증한 뒤 mm로 변환한다.
- `sp`와 정적 지형/육해분포를 보조자료로 확보하고 지하층 마스크를 검증한다. `msl`로 대체하지 않는다.
- `sp`를 아직 확보하지 못했다면 먼저 지상 4변수의 자료/평가 경로를 시험한다. 검증되지 않은 지하 마스크로 상층·저층 훈련을 승인하지 않는다.

**이 프로파일은 현재의 `d83-v1` 또는 두 시간별 입력 Snapshot이 아니다.**
이번 변경은 프로파일과 계획을 선언할 뿐, 6h 어댑터나 예측모델을 구현하지 않는다.
기존 hourly Snapshot 규칙을 느슨하게 바꾸지 않고, cadence가 명시된 별도 계약을 구현할 예정이다.
GraphCast/Pangu 공식 가중치도 부족한 층과 변수를 0으로 채워 실행하지 않는다.

### B. 최종 목표: D83 + P1h

- 6대기변수×13층 + t2m/msl/u10/v10/sp = **83개 순간 상태**, 별도 1h 강수로 총 84출력.
- 실제 `[-1h,0h]` 상태에서 다음 1시간을 예측한다.
- 현재 전지구 캐시에 빠진 50/100/150/200/300/400/600/925 hPa, omega, sp, 실제 중간 시각, 시간별 강수를 확보해야 한다.
- 먼저 제한된 1°·계절 표본 또는 소규모 연도 범위를 검증하고 전기간으로 확장한다.
- 연주기 일반화가 필요한 학습에는 여러 계절/연도가 필요하다. 1개월 지역 pilot을 전지구 조석 성능으로 보고하지 않는다.

## 3. 6h 정보로 1h 전이를 유일하게 증명할 수 없는 이유

회전 전이에서 `R(6ω)=R(6(ω+2πk/6))`이다. 같은 6h 관측을 만족하는 시간경로가 여러 개다.
한 지점의 12h 성분 `a cos(2πt/12)+b sin(2πt/12)`를 6h 간격으로 보면 sine 계수가 사라진다.
새 `scripts/check_benchmarks.py`는 일·반일·상수의 5개 설계열이 1h에서는 rank 5, 6h에서는 rank 4임을 재현한다.
이는 한 지점의 규칙 표본 반례다. 공간파수·물리 제약이 추가 정보를 줄 수 있지만, 없는 실제 hourly 표적을 대신하지 않는다.

따라서 6h 사전학습은 유용한 시작점이며, 필요시 다음 약한 일관성 감독을 사용할 수 있다.

`L_6h = || P_available F_1h^6(x_t) - y_(t+6h) ||²`

그러나 이 감독만으로 시간별 강수 위치, S2 위상, 중간시간 상태가 검증되었다고 하지 않는다.
6h 강수를 6으로 나누거나 6h 상태를 보간한 값은 **파생자료/보조표적**으로 표시하고 실제 1h 관측으로 표시하지 않는다.

## 4. 지역 모델층 자료의 미분가능 변환

모델층 압력은 원자료의 half-level 계수와 단위를 확인하여

`p_half(k) = A(k) + B(k) * ps`

로 구성한다. full-level 정의, `lnsp` 여부, 수직 순서, omega/기하학적 연직속도의 구분을 확인한다.
필요한 target pressure가 모델층 범위 밖이면 검증되지 않은 외삽을 하지 않는다.

고정된 이웃층 사이의 log-p 보간도 ps가 변하면 가중치가 달라진다. 미분가능 NWP 연결에서 ps를 제어변수로
사용한다면 이 가중치의 미분을 누락하지 않는다. bracket/mask가 바뀌는 지점은 조각별 미분과 별도 경계시험으로 다룬다.
오프라인 입력 전처리는 미분이 불필요할 수 있지만, 동화 비용함수 내부의 E-M-P-H는 전체 경로를 검증한다.

surface/model grid가 다르면 동일 point 인덱스로 단순 zip하지 않는다. 구면 기하·벡터풍 기저·면적·layer mass를 맞춘다.
현재 열/수분 toy의 수지는 실제 연직 적분·전체 수분수지의 증명이 아니다.

2020 역사시험과 2025 운영형시험의 점수를 한 표본처럼 합치지 않는다.

## 6. 기존 자료를 사용하는 단계별 작업

1. **R0 재고/계약:** 로컬 담당자가 기존 inspector를 실행한다. 모든 timestep 간격, 변수별 표본, 강수 endpoints,
   파일 손상, sp·정적자료, 자료분할 이력을 추가 확인한다. Git에는 공개 가능한 요약만 올린다.
2. **R1 6h 기준선:** 같은 held-out 초기조건에서 persistence와 train-only climatology를 먼저 계산한다.
   1° 개발격자 결과와 별도 1.5° 공통검증 결과를 나누어 기록한다. 모델 본체는 고정/공유반복을 모두 후보로 둔다.
3. **R2 지역 1h 연결:** 실제 시각 목록에서 연속창을 만든다. 누락을 보간하여 정답으로 만들지 않는다.
   미래 실제 경계장은 예측 입력에 사용하지 않는다. prescribed-boundary 시험은 조건부 시험으로 별도 표시한다.
4. **R3 전지구 hourly pilot:** 실제 hourly 입력·강수·sp·누락층을 확보한 작은 기간으로 1h 전이와 S1/S2를 검증한다.
5. **R4 계절/연도 확장:** 관측강수·고주파·위상·연직관계·JVP/VJP를 통과한 뒤만 0.25°·장기학습으로 확장한다.

구체적인 외부 모델과 승인조건은 [BENCHMARK_PROTOCOL.md](BENCHMARK_PROTOCOL.md),
기계 판독 계약은 [development_targets.json](../benchmarks/development_targets.json)을 따른다.

## 7. 비용 계획을 실제 자료에 맞춰 수정한다

| 항목 | 크기 | 성격 |
|---|---:|---|
| 현재 전체 캐시 | 5.477 TB | 사용자 측 점검의 실제 파일합; 이번 재측정 아님 |
| 같은 44년·30채널·6h·0.25° | 8.009 TB | 비압축 FP32 배열 계산 |
| 같은 자료를 1°로 만든 경우 | 0.503 TB | 비압축 계산; 실제 재격자화 미실행 |
| 전기간 6h sp 1채널 추가 | 0.267 TB | 비압축 계산; 취득/저장 미실행 |
| 5년 D83+P1h·1° 예시 | 0.959 TB | 비압축 계산; 2018–2022는 비용 예시이며 위 시험 split의 학습기간 선언이 아님 |
| 44년 D83+P1h·0.25° 목표 | 134.552 TB | 미래 전체목표; 현재 확보량이 아님 |

8.009 TB와 5.477 TB의 차이를 미래 변수의 보편 압축률로 사용하지 않는다.
기존 134 TB 저장소/32 B200 약33일 계획은 **완전한 hourly D83 본학습 시나리오**로 보관한다.
현재 30채널 6h 자료에 그 학습기간을 그대로 적용하거나 `(30/84)/6` 비율로 줄여 단정하지 않는다.

실행량은 `sum(updates × batch × physical_rollout_steps × ensemble_members)`로 계산하고,
encoder/decoder·내부반복·역전파·손실·입출력의 실측비용을 사용한다.
6h 10일은 40전이, 1h 10일은 240전이지만 서로 같은 학습목표/정확도의 작업은 아니다.
모든 모델의 시간은 compile 포함/제외, batch, precision, read/write, memory, hardware를 함께 기록한다.
실측 전에 GPU 구매·임대·작업 제출을 하지 않는다.

## 8. 이번 변경의 실행 범위

새 외부 점수 레지스트리, 비교 계약, 달력·저장량·aliasing 제조시험을 실행했다.
기존 cache 원문과 evidence는 변경하지 않았다. 신규 ERA5 payload, 모델 가중치, API 인증정보는 받지 않았다.
새 6h/1h 예측모델, 대용량 Zarr 변환, 다른 모델 추론, LAYA, B200는 실행하지 않았다.
기존 D83 240h 실패와 미분가능 NWP 연결의 미해결 사항도 그대로 남긴다.
