# StreamingCAST

전지구 1시간 기상예측을 위한 연구 프로젝트다. 코드·설계·시험·검토 이슈의 기준 저장소는 이 GitHub 저장소다.

## 현재 승인 상태

- 연구용 초기 구성 단계다. 실제 기상예측 성능과 운영 발행은 승인되지 않았다.
- 이전 LoopCast D83 실증은 코드 실행·재시작을 확인했지만, 240시간 합성 성능은 지속예보보다 나빴다. 이 실패를 보존한다.
- 실제 ERA5 스트리밍, 일주기·반일주기의 통합 성능, LAYA 가중치 추론, B200 본학습은 미검증이다.

## 원칙

1. 작은 CPU 시험 → 독립 예측시험 → 단계별 확장 순서를 지킨다.
2. 코드 변경은 작업 브랜치와 PR로 검토하고, 검증 근거를 연결한다.
3. 자료의 유효시각·도착시각·발행시각을 구분한다. 미래 정답을 입력하지 않는다.
4. 1시간 상태전이와 매시간 자료 갱신, 스트리밍 입출력, 온라인 가중치 학습을 구분한다.
5. 24시간·12시간 진폭·위상·최대 발생시각과 지상강수 누적 계약을 필수 검증한다.
6. 대용량 자료·가중치·비밀정보는 Git에 넣지 않는다. 자료·모델 해시와 재현 명령을 기록한다.
7. 반복형·단일통과형은 성능과 비용으로 선택한다. LAYA는 선택적인 제안 계층이며 수치 승인 규칙을 바꾸지 못한다.

이 초기 커밋은 빈 저장소의 기준 브랜치를 설정한다. 후속 구현과 프로젝트 상태는 연결된 이슈·PR에서 관리한다.
